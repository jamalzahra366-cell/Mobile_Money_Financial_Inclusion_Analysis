# Mobile_Money_Financial_Inclusion_Analysis
Project Overview

This project examines patterns in mobile-money use and financial inclusion using data from the Global Findex Database 2025.
The analysis focuses on two main indicators:
- Mobile-money saving: the percentage of adults aged 15+ who report saving money using a mobile-money account.
- Weekly mobile-money deposits: the percentage of adults aged 15+ who report depositing money into a mobile-money account weekly.

The project uses Python for data preparation, analysis, and visualization.

Research Questions

1. Which countries had the highest rates of saving using mobile money?
2. How did mobile-money saving change between 2021 and 2024?
3. Which countries experienced the largest increases or smallest changes?
4. How did the average country-level mobile-money saving rate change over time?
5. Which countries had the highest rates of weekly mobile-money deposits in 2024?
6. Is there a relationship between mobile-money saving and weekly deposit activity?

Data Source

Global Findex Database 2025

The analysis uses country-level data for adults aged 15 and above.

The project includes:

Key Findings

The analysis shows substantial differences between countries in mobile-money saving and weekly deposit activity.

The comparison between 2021 and 2024 also shows meaningful changes in mobile-money saving rates across countries.

The correlation analysis examines the relationship between mobile-money saving and weekly deposit activity in 2024.

The correlation describes an association between the two indicators and does not establish a causal relationship.


Limitations

This is a descriptive analysis and does not establish causal relationships.

Country-level averages may also hide differences between demographic groups within individual countries.

The analysis is limited to the countries and years represented in the available dataset.
